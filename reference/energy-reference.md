# Energy Reference — Master Table

Cross-indexed with per-hex energy tables in each hex .md file.

**Column definitions:**
- **Type:** Source (generates energy), Current (energy flowing through), Reservoir (energy pooled/stored)
- **Flow Direction:** Which way Gareth (Azure Hand) feels it pulling/moving
- **Strength:** How intense the sensation is (faint / weak / moderate / strong / overwhelming)
- **Connects To / Fed By:** What Seek Insight reveals about origin/destination
- **Status:** Discovered (players know) / Undiscovered (GM only)

## Notes

- Gareth senses ALL of these passively upon entering the relevant hex (Azure Hand: "you sense sources, currents, and reservoirs of energy much like you sense the pull of gravity").
- Details (what feeds it, where it connects) require **Seek Insight** roll.
- The ley line is a single continuous current C9 → D8 → E7. It appears in each hex's local table as the relevant segment.
- The sunstone is qualitatively different — warm, divine, not arcane. Gareth senses it but it may feel unfamiliar compared to the ley line.
