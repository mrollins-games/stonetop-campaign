# Stonetop vs. Blades in the Dark — GM Transition Guide

*For a BitD-experienced GM running Stonetop for the first time.*

---

## ✅ SIMILAR (will feel familiar)

1. **Fiction-First Philosophy** — Neither uses turn/round structure; both are pure conversation. Moves trigger from fiction (Stonetop) just as actions arise from fiction (BitD).

2. **GM Doesn't Plan Plots** — Both GMs play to find out. No railroads, no planned storylines.

3. **3-Tier Resolution** — Both use partial success as the most common outcome:
   - BitD: 1–3 (bad) / 4–5 (partial) / 6 (full) / crit (two 6s)
   - Stonetop: 6– (miss) / 7–9 (partial) / 10+ (full) / 12+ (crit)

4. **Threat Clocks** — BitD Progress Clocks ≈ Stonetop Doom Tracks. Same mental model: abstract time pressure made visible.

5. **Playbooks** — Both use pre-structured character sheets with special abilities and XP triggers.

6. **XP Tied to Behavior** — Both reward playing to type and narrative engagement over "winning."

7. **GM Never Rolls for NPCs** — Action rolls do double-duty resolving both PC and NPC actions.

8. **NPCs Need Motivations** — Both demand the GM think about NPC desire and method, not just stat blocks.

---

## ⚡ KEY DIFFERENCES

### Core Resolution

| | **Blades in the Dark** | **Stonetop** |
|---|---|---|
| **Dice** | d6 pool, read single highest | 2d6 + stat modifier (bell curve) |
| **Results** | 1–3 / 4–5 / 6 / crit | 6– / 7–9 / 10+ / 12+ |
| **GM's main lever** | Position + Effect (declared before roll) | GM moves on 6–; move text defines 7–9/10+ |
| **Probability** | Even 1 die ≈ 50% success; more dice = sharply better | Bell curve centered on 7; +stat shifts it |

**Key implication:** No position-setting in Stonetop. The move text self-frames stakes. On a 6–, you pick a GM move that follows from fiction — it's reactive and improvisational.

---

### Session Structure

| | **Blades in the Dark** | **Stonetop** |
|---|---|---|
| **Macro loop** | Free Play → Score → Downtime | Village phase → Expedition → Return |
| **Entry to action** | Engagement roll cuts to action in progress | Fiction-driven; play through preparation |
| **Planning** | Plan type + detail → skip to action | No abstraction; play through it |
| **Downtime** | Formal mechanical phase (payoff, heat, entanglements) | Village scenes between adventures; no automation |
| **Pacing tool** | Engagement roll + flashbacks | None — linear fiction, everything in order |

---

### Player Resources & Consequences

| | **Blades in the Dark** | **Stonetop** |
|---|---|---|
| **Buffer system** | Stress (0–9 track) | HP (class-based) |
| **Mitigation** | Resistance roll (spend stress to reduce harm) | No equivalent — consequences land directly |
| **Permanent marks** | Trauma (personality conditions, earn XP) | Debilities (stat penalties, healable with rest) |
| **Recovery** | Vice indulgence + downtime | Rest, Supply, Recover move |
| **Gear** | Load system (choose per-score) | Fiction-first + Supply tracking on expeditions |
| **Flashbacks** | ✅ Retroactive prep at any time | ❌ Does not exist |

---

### World & Threats

| | **Blades in the Dark** | **Stonetop** |
|---|---|---|
| **Setting** | Pre-built Doskvol (~40 factions, named districts) | Framework provided; collaboratively built |
| **Faction engine** | Automated: status clocks, heat, entanglements | None — threats are GM-discretionary |
| **Threat pressure** | Automated (entanglement table fires after every score) | GM decides when threats advance: "what would it do?" |
| **World-building** | Animate a given world | Build with players via questions + The Almanac |
| **Community mechanic** | Crew (upgrades, rep, tier) | Village of Stonetop (stats, NPCs, welfare) |

---

### Tone & Genre

| | **Blades in the Dark** | **Stonetop** |
|---|---|---|
| **Genre** | Industrial-fantasy crime drama | Bronze Age mythic/folk horror |
| **Tone** | Gritty, morally gray, urban | Earthy, communal, ancient, wonder + dread |
| **Central question** | Will the crew rise to power? | Can the village survive? |
| **PC role** | Criminals seeking wealth/power/freedom | Community protectors with obligations to home |
| **Death stakes** | Crew persists — recruit a replacement | Community loss — the village mourns |
| **Emotional register** | Performative coolness, dark wit | Weight of responsibility, slow dread, communal joy |

## 🧠 KEY MINDSET SHIFTS

### 1. ❌ Stop Setting Position → ✅ Let Moves Self-Frame

No more declaring controlled/risky/desperate before rolls. Move text defines what happens at each tier. On a 6–, pick a GM move that follows from fiction. Lean hard on the GM moves list early on.

### 2. ❌ Stop Cutting to the Action → ✅ Inhabit the In-Between

No engagement roll. The leave-taking, the first night's camp, the slow realization something is wrong — these aren't filler. They're where Stonetop's emotional texture lives. Don't rush to the dungeon.

### 3. ❌ Stop Automating Pressure → ✅ Think Fictionally About Threats

No heat/entanglement table. YOU decide when threats advance: *"What would this threat do if no one stopped it?"* Write threats down, give them impulses, ask that question between sessions.

### 4. ❌ Stop Relying on Player Buffers → ✅ Calibrate Consequences Carefully

No resistance rolls to soften blows. HP and debilities just land. Use soft moves more liberally; save hard moves for when fiction demands them. You no longer have a player-side insurance system.

### 5. ❌ Stop Animating a Pre-Built World → ✅ Build It With Players

Come to session 0 with questions, not answers. *What haunts the old forest? Why does the elder look afraid when the northern road is mentioned?* Let players answer. Write it in the Almanac.

### 6. ❌ Stop Thinking "Crew" → ✅ Think "Village"

The village has stats (prosperity, security, mood). Its welfare is mechanical and emotional. The things the village loves are your most powerful levers. Threaten them.

### 7. ❌ Stop Expecting Flashbacks → ✅ Live With Real-Time Consequences

If they didn't bring rope, they don't have rope. This isn't failure — it's a fictional complication to play through. Players will think harder before leaving.

### 8. ❌ Stop Treating Death as Crew Setback → ✅ It's Community Loss

Characters have named relationships in the village. Their death changes something about the people who stayed home. Weight it accordingly.
