# Skill: /rules-lookup

> Answer rules questions with citations, checking house rules first.

## When to Use
- User asks "how does X work?" / "what happens when..." / "can I..."
- Any mechanical or procedural question about the game

## Procedure

### Step 1: Check House Rules FIRST
Read `gm-notes/house-rules.md`. If the topic has a house rule, that overrides everything.

### Step 2: Find the Rule
1. Check `reference/indexes/rules-index.md` for the topic
2. Open the referenced file and page
3. Read the actual rule text

### Step 3: Present the Answer

```markdown
## [Topic]

**Rule (p.[N]):**
> [Quote or close paraphrase of the actual rule text]

**In practice:** [Plain-language explanation of what this means at the table]

**Common situations:**
- [Example of when this comes up]
- [Edge case to be aware of]

**Related moves:** [Other moves that interact with this]
```

### Step 4: Note Ambiguity
If the rules are unclear or there's a judgment call involved:
- Say so explicitly
- Quote what the book says
- Suggest how to handle it
- Offer to add a house rule to `gm-notes/house-rules.md`
