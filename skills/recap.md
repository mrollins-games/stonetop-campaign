# Skill: /recap

> Summarize recent sessions for the GM or to read aloud to players at session start.

## When to Use
- User asks "what happened last session?" / "give me a recap"
- Start of a new session
- Need to remember what's going on

## Procedure

### Step 1: Determine Scope
- Last session only? Last 2–3? Full campaign so far?
- For players (no spoilers) or for GM (include behind-the-scenes)?

### Step 2: Read Session Files
Read the relevant `sessions/session-NNN.md` files.

### Step 3: Generate Recap

**For Players (read aloud):**
```markdown
## Last Time in Stonetop...
[Narrative, atmospheric 3–5 paragraph summary]
[End with: "And that's where we left off — [cliffhanger/open question]"]
```

**For GM (full context):**
```markdown
## GM Recap — Sessions [N–M]

### Story So Far
[Narrative summary]

### Open Threads
- [Unresolved situation 1]
- [Unresolved situation 2]

### Active Threats
[From threat tracker — current state of each]

### NPC Status
[Key NPCs and their current disposition toward PCs]

### Where We Left Off
[Exact situation at end of last session]

### What's Likely Next
[Based on player actions and active hooks]
```
