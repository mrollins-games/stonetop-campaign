# Skill: Generate Fae

> Create a unique Fae creature using the procedural tables from Book II (pages 100–101).

## When to Use
- Rolling a new wandering Fae encounter
- Populating a Fae domain or POI
- When the "Roll one" entry on `hexcrawl/fae/wandering-fae.md` is triggered

## Procedure

Roll (or pick) from each table in order. Interpret results in context of where/when the Fae appears.

### Step 1 — Preoccupation (1d12)

| Roll | Preoccupation |
|------|---------------|
| 1–2 | Playing / reveling / tricking / subverting |
| 3–4 | Ruling / enforcing / bullying / hurting |
| 5–6 | Striving / making / toiling / growing |
| 7–8 | Collecting / hoarding / obsessing |
| 9–10 | Preening / politicking / gossiping |
| 11–12 | Guarding / watching / sulking / hiding |

### Step 2 — Size (1d12)

| Roll | Size |
|------|------|
| 1 | Tiny (bug- or bird-sized) |
| 2–3 | Tiny (cat-sized or smaller) |
| 4–6 | Small (like a human child) |
| 7–9 | Human-sized |
| 10–11 | Large (like a horse) |
| 12 | Huge (elephant-sized or bigger) |

### Step 3 — Aspects (roll 1–3 times, 1d12 each)

| Roll | Aspect |
|------|--------|
| 1 | Predatory / clawed / fanged / powerful |
| 2 | Horned / antlered / hooved / prancing |
| 3 | Furry / tailed / plump / scampering |
| 4 | Winged / beaked / feathered / spindly |
| 5 | Scaly / squamous / slimy / sinuous |
| 6 | Iridescent / chitinous / bug-like / alien |
| 7 | Treeish / weedish / prickly / stoic / stiff |
| 8 | Leafy / flowering / winding / delicate |
| 9 | Ethereal / fluid / frosty / graceful / aloof |
| 10 | Earthy / rocky / craggy / dirty / stolid |
| 11 | Glittery / starry / luminous / fiery |
| 12 | Puppet-like / artificial / made / hollow |

Also roll 1d6 for **how humanoid** they appear (1 = barely, 6 = very).

### Step 4 — Talents (roll 1–3 times, 1d12 each)

| Roll | Talent |
|------|--------|
| 1 | Illusion / glamour |
| 2 | Shapechanging / transformations |
| 3 | Feats of strength / stamina / labor / skill |
| 4 | Influencing the inanimate / elements / beasts or birds or bugs |
| 5 | Flying / burrowing / phasing / etc. |
| 6 | Messing with time, space, causality |
| 7 | Well-versed in powerful, old magic |
| 8 | Enchanting visage / voice / music / touch |
| 9 | Invisibility / camouflage / stealth |
| 10 | Cursing / blessing / giving / taking |
| 11 | Fae domains: creating / changing them, ensnaring others |
| 12 | Insight / prophecy / dreams and memories laid bare |

### Step 5 — Origin: Bred to… (1d12)

| Roll | Bred to… |
|------|----------|
| 1–2 | Create / maintain a false afterlife |
| 3–4 | Command / compel / enforce / punish |
| 5–6 | Deceive / obscure / protect |
| 7–8 | Entertain / enliven / beautify |
| 9–10 | Nurture / protect / cultivate |
| 11–12 | Work / labor / toil / produce / build |

### Step 6 — Role in the War (1d12)

| Roll | Role |
|------|------|
| 1–3 | Victim / casualty / refugee / prisoner |
| 4–5 | Uninvolved / dissident / loyalist |
| 6–8 | Conscript / recruit / soldier |
| 9–10 | Scout / saboteur / spy / traitor |
| 11 | Marshal / chief / overseer / enforcer |
| 12 | Hero / ringleader / mastermind |

### Step 7 — Lasting Mark (1d12)

| Roll | Lasting Mark |
|------|-------------|
| 1 | Arrogance / defiance / anger / cruelty |
| 2 | Shame / doubt / dread / fussiness |
| 3 | Fame / infamy / enmity / rivals |
| 4 | Nostalgia / denial / delusion / fixation |
| 5 | Patience / exactness / caution / cunning |
| 6 | Quick temper / fierce protectiveness |
| 7 | Duties / obligations / debts |
| 8 | Emptiness / loneliness / grief / ennui |
| 9–10 | Scars / impairments / visible wounds |
| 11–12 | Roll 1d10 twice, combine |

### Step 8 — Corruption Check (1d6)

On a **1**, the Fae is corrupted by the Things Below.

### Step 9 — Name

Fae names tend to be titles, nouns, or descriptive phrases. Mix and match from:
- Plants, beasts, rocks, landscape features
- Natural phenomena, colors, mundane objects
- Emotions, titles, relations, local names

**Simple:** Acorn, Cobweb, Hob, Jackdaw, Kettle, Lark, Moth, Quills, Rill, Robin, Stewpot, Trillium, Uncle Whiskers, Whistler, Wobbles, Yellowtail

**Whimsical:** Bellweather, Bitterlips, Moonbeam, Peasebottom, Poppy o' Twilight, Rainpetal, Stagthorn, Thistledust, Whiteoak, Yellow Britches

**Ominous:** Bonekettle, Father Longfingers, Grinning Nel, the Hangman, the King of Dirges, Old Sorrows, the Pale Sisters, Stonetooth, the Weeping Rose

**Grandiose:** Dawnwhisper, Fireblossom, Breath of Thunder, Hare Starblade, the Midnight Mare, Rain Upon the Valley, Silverstag, the Storm King

---

## Output Format

After rolling, assemble into a stat block and brief narrative:

```
**[NAME]**
[Size], fae, [tags from aspects/talents]
HP [12 base, adjust for size]; Armor 4 (resilience), 0 vs. iron
Damage [weapon] [die] ([range], [tags])
Special qualities: Fae nature; [talents]
Instinct: to [derived from preoccupation]

Moves:
- [3–5 moves derived from talents, preoccupation, and lasting mark]

[2–4 sentence narrative: who they are, what they want, why they're here]
```
