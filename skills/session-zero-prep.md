# Skill: /session-zero-prep

> Comprehensive guide for preparing and running session zero (character creation + introductions).

## When to Use
- Before the very first session
- User asks about session zero prep or character creation

## Procedure

### Step 1: Pre-Session Checklist
Check `gm-notes/todos.md` for any pre-session-1 items, then present:

```markdown
## Session Zero Prep Checklist
- [ ] Review Getting Started chapter (Book I p.15–34)
- [ ] Print/share playbooks with players
- [ ] Prepare Steading playbook
- [ ] Review Setting Overview handout
- [ ] Prepare content safety discussion (Lines & Veils)
- [ ] Note any GM ideas to seed during introductions
```

### Step 2: Run Introductions Guide
From `reference/source-text/book-i-chapters/02-getting-started.md`, remind the GM of the introduction structure:

Each playbook has 4 turns of introductions:
1. **Turn 1:** Name, pronouns, background, origin, appearance
2. **Turn 2:** Special possessions, village contribution
3. **Turn 3:** Unique element (varies by playbook)
4. **Turn 4:** Answer relationship questions (names NPCs!)

**Critical:** Every NPC named during introductions goes into `npcs/_npc-index.md`

### Step 3: Questions the Book Says to Ask
Cross-reference each chosen playbook's "Introductions" section for the specific questions that generate NPCs, relationships, and setting details.

### Step 4: Surface GM Ideas
Check `gm-notes/ideas.md` for anything tagged:
- `Session Zero`
- `Character Creation`
- `Worldbuilding`
- `Religion`
- `Politics`

### Step 5: Steading Setup
After introductions, guide the steading playbook setup:
- Fill in Places of Interest (map)
- Record all NPCs named
- Confirm starting stats
- Note content safety agreements

### Step 6: First Seasons Change
The book instructs a Seasons Change roll after session zero. Reference:
- `reference/source-text/book-i-chapters/15-homefront.md` (p.516–523)
- This generates the first threat hook → leads to `/create-threat`

## Output
After session zero, Copilot should prompt:
- "Shall I record the NPCs created today?"
- "Ready to create threat entries from the hooks established?"
- "Want me to fill in the character sheets?"
